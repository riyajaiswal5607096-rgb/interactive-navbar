# Interactive Navbar (Scroll Effect)

A responsive navigation bar built using HTML, CSS, and JavaScript that changes appearance on scroll and includes smooth hover effects.

## Features
- Fixed navbar at top
- Color change on scroll
- Smooth transition effect
- Hover underline animation
- Responsive layout

## Technologies Used
- HTML
- CSS
- JavaScript

## How it Works
- JavaScript detects scroll using window.scrollY
- When user scrolls down, a CSS class is added
- Navbar style changes dynamically using CSS

live link: interactivenavbarapge.netlify.app
## Project Structure
- index.html → structure
- style.css → styling
- script.js → scroll logic
